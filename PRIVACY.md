# Privacy Policy – GTA6 Autopilot

GTA6 Autopilot is a private tool used only by its owner (The Vampire Path) to upload
the owner's own original Shorts to the owner's own YouTube, Instagram and Facebook accounts.

- It accesses only the owner's accounts, with the owner's permission (OAuth).
- It only uploads videos. It does not read, store, sell or share any other user data.
- Access tokens are stored encrypted in GitHub Actions secrets and are never shared.
- No data from other people is collected.
