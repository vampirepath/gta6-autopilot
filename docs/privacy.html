Privacy Policy

Last updated: 16 November 2026

Vice Daily Shorts ("the tool") is a private tool operated by The Vampire Path to publish videos to its own YouTube channel. This policy explains what data the tool uses.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data we access

  • An OAuth 2.0 refresh token for the operator's own YouTube channel, with the youtube.upload scope only, used to upload videos.
  • The IDs of videos the tool uploaded, so it does not upload the same video twice.

The tool does not access, collect or store any data about other YouTube users, viewers or channels, and it uses no cookies or tracking.

How data is stored and shared

The OAuth token is stored as an encrypted secret in the operator's GitHub account and is never shared with anyone. Uploaded video IDs are kept in a small database inside the project. No data is sold or shared with third parties.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. Stored data is deleted within 7 days of revocation or on request, and data is refreshed or deleted at least every 30 days as required by YouTube's policies.
